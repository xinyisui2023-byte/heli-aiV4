# HarmonyLink v4.0 — 流量摆渡升级版

> 基于 2026-05-23 版本（v3.0）全面升级，新增三大流量摆渡机制
> 创建日期：2026-05-30

---

## 核心升级目标

解决"综艺内容在腾讯/深圳卫视等平台分发，但用户数据和互动无法回流到合力生态"的核心问题。

**战略思路**：不对抗平台，做"流量摆渡"——把平台方当获客漏斗，把用户关系沉淀在合力生态。

---

## v3.0 → v4.0 新增模块

### 1. 扫码签到 + 观剧积分任务（最高优先级）
- **新增页面**：`page-qr-task`（移动端H5优先）
- **功能**：综艺每集结尾放二维码 → 用户扫码进入合力生态 → 选择剧集 → 签到/截图上传 → 验证 → 发放 WATCH 积分
- **用途**：不依赖平台API，用户主动行为触发积分，完成从平台到生态的第一步摆渡
- **触发方式**：综艺视频结尾二维码、社交媒体分享链接、邮件内嵌链接

### 2. 邀请裂变页（第二优先级）
- **新增页面**：`page-invite`
- **功能**：生成带个人ID的邀请链接/海报 → 被邀请人注册 → 双方获积分 → 邀请统计与排行榜
- **用途**：跟投资机构邮件外发任务打通，人来了之后有留存裂变机制
- **联动**：邮件中的链接带 `?ref=xxx` 参数自动归因

### 3. 直播入口模块（第三优先级）
- **新增模块**：`app-live.js`
- **功能**：视频号直播预告/嵌入 → 挂载小程序链接 → 弹幕互动 → 积分回流
- **用途**：在腾讯生态内合规跳转，直播是综艺分发的重要补充渠道

## 技术要点

- **纯前端实现**，所有页面均为 SPA 单页应用
- **移动端优先设计**，扫码任务页专为手机扫码场景优化
- **localStorage 模拟用户数据**，后续可对接后端 API
- **微信环境检测**，自动判断是否在微信内打开，引导小程序跳转

## 部署计划

1. 先在 heli-ai.com 部署（GitHub Pages 或云服务器）
2. 综艺视频结尾嵌入扫码二维码（指向 heli-ai.com/qr-task）
3. 邮件发送模板更新，链接带邀请参数
4. 视频号开通后挂载小程序链接
